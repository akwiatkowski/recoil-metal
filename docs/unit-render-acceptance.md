# Unit render acceptance — engine model vs wiki build-button

2026-09-29. Every unit and building the `supcom-wiki` mirror carries a
`*_build_btn.png` icon for (170 ids) was rendered headless and compared
side-by-side against that icon.

The pass then widened past the icons: all 568 blueprints in `units.scd` were
rendered the same way, and the 399 without an icon were scanned for empty
frames and texture fallbacks. Only deliberate invisibles (the zero-scale
XSC9010/XSC9011 jammer-crystal markers) and content gaps (below) remain.

## Rig

`tools/render_units.py` drives the existing `--screenshot` path:

```
recoil-metal /tmp/flat.smf --gamedata <retail-fa>/gamedata \
    --units /units/<ID>/<ID>_unit.bp 1 --focus 2.2 \
    --camera 45 45 --no-hud --no-interpolate \
    --screenshot build/unit-icons/renders/<ID>.png 512 512
```

- `/tmp/flat.smf` is generated by the script: a legal Recoil SMF, 128×128
  squares, dead flat — studio floor, no relief to hide a model in.
- `--camera PITCH YAW` (new, degrees) overrides the orbit angles after
  `--focus`/`--look` pick the target. 45°/45° approximates the icons'
  three-quarter view.
- `--no-hud` (new) clears HUD, minimap, rings, decals and particles after
  `composeHeadlessInterface` runs — the census lines still print, the pixels
  are world-only.
- `--focus` is in model radii; experimentals get 2.8, everything else 2.2.

Outputs: `build/unit-icons/renders/<ID>.png`, per-unit side-by-side sheets in
`build/unit-icons/sheets/`, review grids in `build/unit-icons/grids/`, all
linked from `build/unit-icons/index.html`. Re-run: `python3
tools/render_units.py [ID...]`.

## Bugs found and fixed doing this

| Defect | Cause | Fix |
|---|---|---|
| All `RULEUMT_Water` units rendered empty frames | `resolveUnits` skipped `scatterOnLand` for surface-water types, so a dry map produced zero instances | `SceneBuild.cpp` — beached scatter fallback |
| All `RULEUMT_SurfacingSub` subs rendered empty frames | Spawned `submerged` with a negative `submarineOffset`; `placeOnMotionLayer` sunk them under the flat ground | `SceneBuild.cpp` — subs spawned on dry ground surface instead |
| XRL0403 Megalith rendered untextured white | Blueprint LOD0 names another unit's mesh (`xrl0404_LOD0.scm`) and no `AlbedoName`; mesh-relative texture lookup found nothing | `SceneBuild.cpp` — `unitTextureInVfs` falls back to the blueprint's own `<id>_Albedo.dds` convention |
| Civilian/wreck blueprints rendered blank (XAC*, XEC*, XRC*, XSC16/17xx, URB3103, ~20 ids) | Their only mesh is `Display.PlaceholderMeshName` — a bare unit id ("UEC1101") no loader resolved | `UnitBlueprint.cpp` — parsed the field; `resolveMeshInVfs` tries `/units/<id>/<id>_lodN.scm` |
| `test_unit_scenarios` #1796 hard-failed without the T5 drive | Hardcoded `/Volumes/Samsung_T5` archive path | test now honours `RM_FA_ROOT`, skips if absent |

The two placement fixes and the texture fallback are load-bearing for real
scenes too, not just the studio map: any map without water (or a sub caught
ashore) hit the same code.

## Verdicts

- **All 568 blueprints render or are authored invisible.** 562 draw their own
  mesh; four name no mesh at all by design (UAB5204/UEB5204/URB5204 "Concrete"
  cinematic blocks, URB5206 "Tracking Device" probe), and two spawn at
  `UniformScale = 0` (XSC9010/XSC9011 jammer-crystal markers). The 399 without
  icons were reviewed in the same passes — every factory, wall, civilian
  structure and OP unit draws its own mesh and textures.
- **169 of 170 render correctly.** Mesh, albedo, team-color spec map, normals
  and pose all check out against the icons: commanders, experimentals
  (Monkeylord, Megalith, Galactic Colossus, Fatboy, Atlantis, Tempest, CZAR,
  Ythotha), Seraphim's curved hulls, beached navy hulls, surfaced subs, air
  transports, factories, and the full T1–T3 building set.
- **UEL0209 (UEF T2 Field Engineer) has no blueprint in this gamedata
  snapshot** — the only icon whose unit is missing from the content, not a
  render defect.
- Cosmetic deltas, judged acceptable: units wear the default first-palette
  team colour rather than the icon's faction lighting; XSL0402 renders as its
  energy-signature mesh without the glow FX the icon adds; XEA3204 (Novax
  satellite) is a legitimately tiny model read at 2.8 radii; builds sit on
  flat ground rather than each icon's aqua backdrop.

Every other render matches its icon's silhouette, texturing and proportions.
No unit renders as a fallback blob, placeholder or empty frame.
